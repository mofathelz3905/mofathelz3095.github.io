Process Writeup

Name: Mofathel Z

Course: SEP10 Web Design

Period: 2

Concept: HTML Elements

Context

I am learning how HTML is used to create and organize content on websites. HTML stands for HyperText Markup Language. It uses elements and tags to tell a browser how to display text, images, links, and other content. Learning HTML is helping me understand how webpages are built.

Learning Experience

During this unit, I practiced HTML on FreeCodeCamp. I learned how to use headings, paragraphs, images, links, and lists. Headings, such as <h1> and <h2>, help show the title and sections of a webpage. The <p> element is used for paragraphs, which makes it easier to organize longer pieces of text.

I also learned about the <main> element. It identifies the main content of a webpage and helps organize the page’s structure. Most HTML elements have an opening tag and a closing tag. For example, a paragraph starts with <p> and ends with </p>. Some elements, like <img>, do not need a closing tag.

For images, I learned to use the <img> element with the src attribute. The src tells the browser where to find the image. The alt attribute gives the image a text description in case it does not load and helps people who use screen readers.

I practiced making links with the <a> element. The href attribute tells the link where to go. A link can take someone to another website or to a different section on the same page. I also learned that an image can be made clickable by placing it inside an anchor element.

Another topic I learned was lists. An unordered list uses bullet points, and an ordered list uses numbers. Both types of lists use <li> elements for each item. For example:

<ul>
  <li>First item</li>
  <li>Second item</li>
</ul>

<ol>
  <li>First step</li>
  <li>Second step</li>
</ol>

Challenges

One topic that took me some time to understand was internal links. At first, I was confused about how href and id work together. I learned that the link’s href uses a # followed by the ID of the section it should go to. The section itself needs to have the matching ID. For example:

<a href="#contact">Go to the contact section</a>

<h2 id="contact">Contact</h2>

I also had to remember that the ID must match exactly. If the spelling is different, the link may not take me to the right place. Practicing with examples helped me understand how the two parts connect.

Another challenge was making small typing mistakes. For example, I could accidentally type scr instead of src when adding an image. I also sometimes had to reread instructions because terms like “attribute” or “value” were new to me. Looking carefully at examples and checking each part of my code helped me figure things out.

What I Learned About Myself

I learned that I can understand challenging topics when I take my time and keep practicing. Sometimes I need to read an explanation more than once, but I can improve by trying examples and asking questions. I also learned that paying attention to small details is important when writing code because one letter or symbol can make a difference.

Steps for the Future

I plan to keep practicing HTML and reviewing my notes so I can remember how different elements and attributes work. I will check my code for spelling mistakes, missing brackets, and incorrect values before I finish an assignment. If I do not understand something, I will ask questions and try another example.

As I learn more, I hope to create complete webpages with headings, images, links, and organized sections. I know I still have more to learn, but I feel ready to keep improving my web design skills.
